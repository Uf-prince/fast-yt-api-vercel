Fast YT API ⚡

YouTube download API — direct googlevideo CDN links via youtubei.js iOS client

Deployed on Vercel
GET /api/info?url=YOUTUBE_URL
Returns JSON: title, author, thumbnail, duration, and all available formats with direct download URLs
GET /api/download?url=YOUTUBE_URL&type=audio|video&quality=360|720|1080
Streams or redirects to the media file. type=audio for audio only, quality for video resolution

Example: /api/info?url=https://www.youtube.com/watch?v=dQw4w9WgXcQ

Powered by youtubei.js — returns pre-signed direct googlevideo.com URLs (fast CDN, no throttling).
The download endpoint streams from Google's CDN, or falls back to a 302 redirect if streaming is blocked.
